# 角色语音维护

拾课 1.9.0 中，阳茉莉和希尔维娅各有早晨、午间、夜晚各 38 句的离线日语语音，每人 114 段，共 228 段。中文语录继续显示在卡片上。六条情境提示不进入随机换句池，也不自动播音；纱雾和简约主题目前没有语音。

## 使用与播放规则

在「设置 → 当前角色语音」开关语音，默认开启；阳茉莉和希尔维娅分别显示自己的名称。点击角色或语录，先从当前时段池换到新句，再播放它对应的日语录音。首次进入、切换页面、刷新小组件、半小时自动轮换均不自动播放。

应用和所有小组件共用一个播放会话。准备、播放及临时失去音频焦点而暂停时，重复点击均忽略，不截断、不排队；当前文字和立绘固定到音频播放结束。`MediaPlayer.OnCompletionListener` 是正常解锁依据，不用计时器估计播放时长。旋转屏幕、退出到桌面继续播完当前句。“正在说话 · 播完再换句”仅在首次成功开始播放的会话显示；首次状态独立于首次换句提示，由应用、小组件和全部主题共用，保存到本机偏好。重启、切主题、升级不重置。准备失败不会消耗该首次提示；准备中与焦点暂停仍提供状态反馈。

系统来电或其他音频暂时占用时暂停，获得音频焦点后续播；永久失去焦点、拔下耳机、系统终止服务、资源损坏等情况结束会话并恢复操作。用户主动关闭语音、关闭角色或切换主题会取消当前句。语音失败有提示，避免锁死操作。上述取消或系统中断不等于完整播毕。

当前采用短时 `mediaPlayback` 前台服务，播放时显示静默状态通知，播放完立即移除。服务和桌面播放接收器均不导出，仅响应用户点击。没有开机自动播音，没有后台联网合成，也不会上传课表、登录状态或声音文件。

## 增减语音

正式入口是 `app/src/main/assets/themes/<主题id>/theme.json` 中可选的 `companion.voices`：

```json
{
  "line": "早、早上好……今天的课表，我陪你一起看看吧。",
  "file": "voice/morning_001.ogg",
  "text": "お、おはよう……今日の時間割、一緒に見てみようか。",
  "language": "JA"
}
```

`line` 必须与中文语录完全一致，以文字关联而非数组下标关联，调整语录顺序不会串音。删除语录后，遗留映射不会参与播放；也应清理相应配置和音频以减小包体。新增句子尚无映射时仍可显示，静默换句。新增角色可以按同样格式加入语音，无需修改播放实现。

音频放在主题目录内，支持 `.ogg`、`.wav`、`.mp3`、`.m4a` 相对路径，禁止绝对路径、上级目录及网络地址。每个中文句子只能有一条映射。替换资源后递增主题 `version`。Ogg 资源不压缩打包，供 Android 直接从资源文件描述符读取。

## 本地重新生成

`docs/阳茉莉语音台本.json` 保存此次分时日语适配，数量和顺序对应中文池；生成脚本合并中文后写入正式主题配置。`docs/阳茉莉语音生成记录.json` 保存生成器、参考片段定位、文本、时长和最终文件 SHA-256。播放使用预生成文件，不依赖用户手机安装 TTS。

使用已有 IndexTTS-2.5 Python 环境调用 `scripts/generate-himari-voices.py`，传入 `--tts-root`（IndexTTS 目录）和 `--dataset-root`（包含 `dataset_40k` 及来源清单的目录）。可选 `--preview-dir` 复用已经确认的六段试听。

脚本依据拼接清单从 `himari_001.wav` 第 5.51 秒开始提取完整 6.48 秒对白，作为整批统一参考；不把整个 90 秒拼接段送入模型。不训练 RVC，不改变音高、语速，不修改全局默认音色，不安装或升级依赖。使用现有 GPU 串行锁，原始 WAV 留在忽略的 `work/`，应用只带压缩后的 Ogg。

参考游戏录音和完整训练集留在本机，不纳入仓库。应用语录及日语适配是原创应用文案，合成音频不是原作录音；角色及原作权利仍属于各自权利人。

实现依据：[Android 音频焦点](https://developer.android.com/media/optimize/audio-focus)、[前台服务后台启动规则](https://developer.android.com/develop/background-work/services/fgs/restrictions-bg-start)、[前台服务类型](https://developer.android.com/develop/background-work/services/fgs/service-types)。

## 希尔维娅生成

`docs/希尔维娅语音台本.json` 与中文分时池逐句对应；`docs/希尔维娅语音生成记录.json` 保存统一参考文件名及校验值、生成文本、时长、采样率和输出校验值。声音参考来自用户提供的原声目录，选用 `100800540.ogg` 的完整约 5.2 秒日常对白，转单声道 WAV 供推理；不使用整段训练集，不修改全局参考音色。

在已有环境中运行 `scripts/generate-sylvia-voices.py --tts-root <IndexTTS目录> --reference <完整单句音频路径>`。脚本使用 GPU 串行锁、文本与参考校验值命名的断点缓存、时长/非静音/有限采样检查和 Ogg 回读验证。仅将本次生成的 `sylvia/voice/` 文件纳入 APK；阳茉莉已有录音保持不变。生成内容是原创应用文案的合成朗读，并非原作配音。
