# 在线更新与资源发布

1.11.0起，「设置 → 更新与资源」连接公开GitHub仓库。进入设置检查一次应用版本；手动「检查更新」随时重试。旋转屏幕沿用当前检查、下载与待安装状态。发现新版后可查看Release的完整更新说明，下载完成点击「安装更新」，首次按系统提示允许拾课安装应用，再由系统确认安装。

「在线主题资源」展示阳茉莉、纱雾、希尔维娅等目录条目、版本、下载大小、素材说明和安装状态。未安装时可下载，已有旧版时显示更新；下载后沿用ZIP预览确认。取消或校验失败不会替换主题或课程。「导入主题包」仍可从本地ZIP导入。

下载显示进度，可以取消后重试。离开设置、切到课表或旋转屏幕时，同一进程内任务继续；本版不提供断点续传或系统重启后自动恢复。下载时请保留网络和足够空间。网络不可达、GitHub限流或服务器异常均明确显示失败，不能当作“已是最新版本”。已安装主题和本机课表不依赖GitHub联网。

## 仓库目录

- `distribution/themes.json`：在线主题目录。固定从`main`读取，可独立更新，不需发布新APK。
- `distribution/notes/`：每版应用的更新说明，发布到GitHub Release后在应用显示。
- `theme-packs/<id>/`：主题源素材；`scripts/package-themes.py`生成可导入ZIP。
- Release的`shike-update.json`：应用版本描述，由`scripts/prepare-update.py`生成。
- Release的`shike-<version>-compact.apk`：该版本完整安装包。客户端按整数`versionCode`判断新旧，不使用版本名称的字符串排序。

应用查询GitHub REST `releases/latest`，只接受正式版。找到`shike-update.json`，校验其GitHub附件digest后读取`versionCode/versionName/minSdk/assetName`；描述里的tag必须匹配Release。实际安装包的大小、SHA256来自同一Release附件元数据，更新说明来自`body`。草稿、预发布和缺少描述的旧发布均不作为可安装更新。

## 发布应用

1. 增加`app/build.gradle.kts`里的`versionCode`和`versionName`，完成构建、测试和签名验证。沿用既有签名才能覆盖安装；签名密钥只放本机。
2. 在`distribution/notes/<version>.md`写更新内容。
3. 构建`assembleRelease`，将APK放到`dist/拾课-<version>-compact.apk`。
4. 提交并推送代码，确保发布对应的HEAD已在GitHub。
5. 运行发布脚本，先创建草稿、上传APK、更新描述和校验文件，并核对GitHub的size/digest；指定`--publish`才会公开发布并设为最新版本：

```powershell
python scripts/publish-release.py --apk 'dist/拾课-1.11.0-compact.apk' --notes-file 'distribution/notes/1.11.0.md' --upload-proxy http://127.0.0.1:7892 --publish
```

脚本从本机Git凭据管理器获取凭据，仅保留在进程内，不打印、不写入文件。省略`--upload-proxy`即直连；省略`--publish`仅准备草稿。遇到同名附件时只复用内容完全一致的文件，不覆盖不同内容。最终公开后验证tag与HEAD一致。

## 发布或更新主题

1. 增减`theme-packs/<id>/`的素材和配置；内容变化请增加主题`version`，不要覆盖已发布的同版本ZIP。
2. 运行`python scripts/package-themes.py`生成`dist/themes/`。把新ZIP上传到GitHub的公开正式Release（推荐附在已有应用Release；专用资源Release请标记为预发布，避免覆盖应用最新正式版）。
3. 用`scripts/update-theme-catalog.py`更新对应条目，保留其他主题；示例：

```powershell
python scripts/update-theme-catalog.py --id himari --release-tag v1.10.0 --notes-file 'docs/阳茉莉资源说明.txt'
```

说明文件是UTF-8纯文本，最多4000字。脚本根据实际ZIP生成大小、SHA256和下载URL；确认附件已经公开且内容相同，再提交推送`distribution/themes.json`。当前三个主题直接复用1.10.0的原ZIP，未重复打包或重新生成素材。

目录schemaVersion为1，每项包含`id`、正整数`version`、`name`、`description`、`notes`、`minVersionCode`、`url`、`bytes`和`sha256`。仅支持本仓库的HTTPS Release附件URL。客户端检查最低应用版本；下载ZIP还必须与目录中的id和version完全一致，之后执行已有的路径、压缩大小、图片解码及音频校验，确认前不会修改当前主题。

## 安装边界

APK下载限定大小并验证SHA256，再读取Android安装包，核对包名、新版本号、Android最低版本和签名与当前应用一致。安装前再次校验文件；仅向系统授予专用更新缓存目录内该APK的读取权限，不对外暴露课表或主题目录。系统安装授权和最终安装确认由用户完成，不提供静默安装。

本版没有新增下载库，也没有将角色素材放回基础APK。资源包保存在应用私有目录；删除下载缓存不影响已安装主题。清除应用数据或卸载前仍需自行备份课表。
