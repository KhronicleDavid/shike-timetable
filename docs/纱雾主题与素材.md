# 纱雾主题与素材

拾课 1.6.0 新增「纱雾主题」，在「设置 → 整体主题」中选择。应用和桌面小组件同步切换角色、语录与颜色。阳茉莉和简约主题仍保留，默认主题及已有课程不变。

## 视觉与配色

以用户提供参考图中的银白长发、蓝绿眼睛、粉色蝴蝶结为视觉依据。浅色使用雾白底、樱粉主色、冰蓝辅助色与淡紫点缀；深色使用紫灰底、柔粉文字和蓝灰卡片。主色不是沿用阳茉莉的薄荷绿。

| 用途 | 浅色 | 深色 |
| --- | --- | --- |
| 主色 / 按钮 | `#944466` | `#F0AFCC` |
| 辅助色 | `#466884` | `#ABCDEC` |
| 页面背景 | `#FCF8FC` | `#1E1B28` |
| 页面文字 | `#333242` | `#ECE5F0` |
| 陪伴卡起点 | `#F9E3EE` | `#483044` |
| 陪伴卡终点 | `#E4EFFB` | `#293C53` |

配色应用于首页、周课表、课程色块、编辑、设置、画册、导入入口及小组件。小组件使用卡片起点色作为底色。课程仍保留原来的六个颜色编号，只按主题对应到新颜色。

## 六幅适配图

均使用内置 imagegen，参考用户图片生成独立透明底二创；没有改动用户原图。常规立绘保留半身构图，Q 版强调完整的小轮廓，以适合窄卡片和桌面。最终素材保存在项目目录，不依赖本机图片集路径。

| 时段 | 常规立绘 | Q 版 | 场景 |
| --- | --- | --- | --- |
| 早晨 | `sagiri_morning_portrait.png` | `sagiri_morning_chibi.png` | 抱速写本、轻轻招手 |
| 午间 | `sagiri_noon_portrait.png` | `sagiri_noon_chibi.png` | 数位板与画笔、专注画画 |
| 夜晚 | `sagiri_evening_portrait.png` | `sagiri_evening_chibi.png` | 抱枕、合上的书、安静休息 |

每时段两幅图进入应用轮换池，画册显示全部六幅。常规立绘的 `compactFile` 指向同一时段 Q 版，小组件因此优先显示 Q 版；语录和用户手选状态仍与应用共享。旧主题不填写 `compactFile` 时继续使用原图片。

配置与图片：`app/src/main/assets/themes/sagiri/theme.json`、同目录 `artwork/`。完整生成提示记录见 [纱雾素材生成记录](纱雾素材生成记录.json)。

参考图来自用户图片集中的 `1B56C164D8E295F0B5CF1E5E6C44E195.jpg`，其余三图一并查看，用于理解角色形象，没有将整套原始图片复制进安装包。原图画师与发布出处未提供，不将其当作自有素材或官方授权素材。角色与原作版权属于原权利人，画册保留角色、原作与 AI 重绘说明。

## 126 条陪伴语

早晨、午间、夜晚各 40 条，另有 6 条操作情境用语，完整阅读版为 [和泉纱雾陪伴语](和泉纱雾陪伴语.md)。正式 `theme.json` 的 `companion` 是唯一可维护文案源，早期草稿已迁入，避免两份配置不同步。

角色依据为 [官方角色页](https://eromanga-sensei.com/character/) 与 [官方作品简介](https://eromanga-sensei.com/introduction/) 中的室内生活与插画创作设定（查阅于 2026-10-15）。短句、停顿、直率中略带害羞，是面向课表应用的创作处理，全部文案均非原作引文，不增添身世、共同经历或用户关系。

使用手机本地时间：05:00–10:59 为早晨，11:00–16:59 为午间，17:00–次日 04:59 为夜晚。点击换句仅抽取对应时段，优先避开最近五句。首次点击提示沿用全局状态，增加或切换主题不会重新显示。夜晚池未再细分傍晚与深夜。

## 后续维护

增减图片、台词和配色均直接维护 `theme.json`，无需新增角色枚举。修改后递增该主题的 `version`，新增可选紧凑图字段沿用 `schemaVersion: 1`，其他主题保持兼容。操作步骤见 [主题与角色素材维护](主题与角色素材维护.md)。

已安装旧版的用户需要安装 1.6.0 或更新版，才能在主题列表中看到纱雾；这仍是随应用发布的内置主题，不是在线下载主题。
