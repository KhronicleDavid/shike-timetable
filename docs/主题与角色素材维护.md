# 主题与角色素材维护

适用版本：拾课 1.10.0。角色以独立ZIP导入，基础安装包只含简约主题。当前提供「阳茉莉主题」「纱雾主题」「希尔维娅主题」和无角色的「简约主题」。希尔维娅已有分时对话与离线日语配音；真白的角色素材留待以后补充。

## 应用中使用

在「设置 → 整体主题」切换，首页、课程配色、设置、编辑、画册、导入入口及桌面小组件共用主题选择。浅色、深色和跟随系统属于独立的「明暗模式」，切换角色主题不会改变课程、学期或作息。

角色主题的时间划分统一使用手机本地时间：早晨 05:00–10:59，午间 11:00–16:59，夜晚 17:00–次日 04:59。自动轮换和点击换句都先确定实际时段，只读取对应语录池；情境用语不混入随机池。优先避开当前句及最近五句，内容少时逐步放宽历史限制；只有一句或一幅图时继续使用该内容，不会崩溃或借用其他时段的语录。

「点点我 · 换句话」是首次交互提示。在应用或任一小组件首次点击角色、语录或提示后，提示会在两处隐藏；重启、换主题、到新时段和应用升级不会重置。点击换句功能和无障碍操作名称继续保留。清除应用数据或重装后会重新显示。

## 目录与唯一注册入口

```text
app/src/main/assets/themes/   # 仅内置简约主题
  catalog.json
  minimal/theme.json
theme-packs/                 # 独立角色源文件，不打进正式APK
  himari/theme.json
  himari/artwork/
  himari/voice/
  sagiri/theme.json
  sagiri/artwork/
  sylvia/theme.json
  sylvia/artwork/
  sylvia/voice/
```

每个角色目录用 `scripts/package-themes.py` 打包成一个ZIP，手机在「设置 → 导入主题包」安装并自动注册。基础APK的catalog仅注册简约主题，不再维护外部角色列表。详细包结构、替换更新、移除与限制见 [外部主题包与体积精简](外部主题包与体积精简.md)。

## 增减语录

只有插画的新角色可以完全省略 `companion.quotes`，此时卡片和小组件隐藏语录区，点击角色仅切换当前时段的插画，不用编造占位句。开始配置 `quotes` 后，三个时段仍各需至少一句，保持原有校验规则。

语音通过可选 `companion.voices` 按中文原句对应；调整数组顺序不会串音，删除句子后的遗留映射会被忽略。补音、重绘音色与本地生成方法见 [角色语音维护](角色语音维护.md)。播放中的句子和立绘固定，直到播完；其余随机与时段规则保持不变。

编辑对应主题 `theme.json` 的 `companion.quotes.morning`、`noon`、`evening` 数组。每条是一个字符串，增删数组项目即可，无需修改 Kotlin。三个时段各保留至少一句，不在同一池内重复；建议每句简短，以便卡片和小组件显示。

`contextLines` 用于特定操作，键名保持稳定：`free_day`（今日无课）、`empty_week`（空课表）、`classroom_pending`（教室待定）、`course_saved`（保存成功）、`search_empty`（搜索为空）、`import_saved`（导入成功）。删除某项后页面使用普通提示，不会改用其他角色或其他时段的台词。

## 增减立绘

把图片放入该主题的 `artwork/`，并在 `companion.artworks` 数组添加一项。例如：

```json
{
  "id": "new_morning",
  "label": "早晨·新图",
  "file": "artwork/new_morning.png",
  "periods": ["morning"],
  "scenes": [],
  "framing": "fit"
}
```

`id` 是稳定标识；`label` 是画册名称；`file` 使用主题目录内的相对路径；`periods` 决定进入哪个时段的图池，可同时填写多个时段。`framing` 可为 `fit`（显示完整画面）或 `crop`（填满肖像区域）。透明 PNG 或 WebP 更适合角色立绘。

可选的 `scenes` 包括 `greeting`（迎接）、`study`（学习/导入）、`empty`（空状态）、`rest`（休息）、`original`（原画）。页面需要某个场景但未指定时使用该主题的第一幅图。纯画册图可以把 `periods` 留为空数组；每个时段仍须至少有一幅可轮换的图。

删除时移除这一项并删除对应图片文件即可。画册、场景选择和轮换列表会从同一份配置重新计算，不需要维护资源枚举、图片映射或第二份画册清单。升级后已保存的句子或插画不再存在时，自动回到当前时段的有效内容。

可选字段 `compactFile` 指定同一时段的小组件紧凑版图片，例如 `"compactFile": "artwork/sagiri_morning_chibi.png"`。小组件优先加载它，未提供时使用 `file`；应用与画册仍显示 `file`。路径规则相同，且文件必须存在于该主题内。若也希望 Q 版能出现在应用轮换和画册中，将它作为独立的 `artworks` 项配置即可。删除图片时也要检查是否被其他项的 `compactFile` 引用。

## 新增角色主题

1. 将 [主题模板](主题模板.json) 复制到 `theme-packs/<新id>/theme.json`，修改 `id`、名称、描述和版本。
2. 添加真实图片，替换模板中的占位图片路径、角色名字、署名与三组占位文案。模板的一幅图可以用于三个时段。
3. 修改 `palettes.light`、`palettes.dark`，使用打包脚本生成独立ZIP。
4. 在手机「设置 → 导入主题包」选择ZIP并确认，即可使用，无需重新构建APK。

无角色主题可参考 `minimal/theme.json`，省略整个 `companion`。主题的浅深色板控制通用界面和小组件颜色，`cardStart`、`cardEnd` 控制应用陪伴卡渐变，小组件使用 `cardStart` 作为卡片底色。`courseAccents` 保留六项，让已有课程的颜色编号在不同主题中都能对应。

`schemaVersion` 是配置结构版本，目前为 1；`version` 是各主题自己的内容版本，修改素材或文案后递增。Android 应用版本独立管理。角色版权与图片来源在主题 `attribution` 和相应设计记录中保留，不把二创语录当作原作引用。

## 检查与更新

```powershell
.\scripts\build.ps1 -Tasks @('testDebugUnitTest', 'assembleDebug')
```

测试会加载已注册主题，检查结构、每个时段的有效内容与图片路径，覆盖单句/单图、随机规避、跨时段及素材增删。补充主题时不需要为数量修改测试断言。连接测试设备后，可运行 `connectedDebugAndroidTest` 检查实际页面及桌面宿主。

课程和备份仍由原有 `ScheduleStore` 管理；主题选择和角色显示开关保存在 `shike_appearance`，各主题的手选内容、近期历史和一次性提示状态保存在 `shike_companion_interaction`。1.4 版的角色开关与阳茉莉手选内容有兼容读取，课表 JSON 格式保持不变。

1.9.0 起播放提示也只出现一次；这与“点点我 · 换句话”的首次提示分别保存，详见 [角色语音维护](角色语音维护.md)。
