## 角色依据与写法

角色为《エロマンガ先生》的和泉纱雾（和泉紗霧 / Sagiri Izumi）。官方角色页与作品简介确认了她主要待在房间、从事插画创作的设定：[官方角色页](https://eromanga-sensei.com/character/)、[官方作品简介](https://eromanga-sensei.com/introduction/)。查阅日期为 2026-10-15。

本包围绕画板、草稿、配色、安静的房间等意象写作；短句、停顿、直率中带一点害羞和小别扭，是为课表应用采用的创作方向，不是官方性格描述的逐字翻译。与阳茉莉较开朗的语气区别开来，不仅替换角色名字。

全部 126 条均为原创应用文案，不是原作台词摘录或官方授权文本。不添加新身世、共同经历或约定，不预设用户与角色的亲属、恋爱关系。图片与角色署名须在接入时根据实际素材来源补充。

## 时段与使用

| 字段 | 手机本地时间 | 数量 | 用途 |
| --- | --- | --- | --- |
| `quotes.morning` | 05:00–10:59 | 40 | 起床、准备出门、晨光与开始创作 |
| `quotes.noon` | 11:00–16:59 | 40 | 午饭、课间休息、下午学习与画稿 |
| `quotes.evening` | 17:00–次日 04:59 | 40 | 晚饭、收尾、明日准备与晚安 |
| `contextLines` | 对应业务操作发生时 | 6 | 无课、空课表、教室待定、保存、搜索、导入 |

沿用当前引擎：点击换句仅抽取实际时段的语录池，优先避开当前句与最近五句；自动轮换按半小时保持稳定。首次点击提示沿用全局已保存状态，不因新增主题而重现。情境用语只在对应业务场景显示，不混入随机池。

时段池中的句子不承诺已发生的操作，不引用具体课名、课程数量、天气或用户位置。涉及上课的提醒是通用建议，不代表系统判断当下有课。夜晚池跨度较大，包含傍晚与晚安语句；当前引擎未细分晚餐、深夜子时段。

## 收到图片后接入

1. 在 `app/src/main/assets/themes/sagiri/` 建立完整主题，使用 [主题模板](../../主题模板.json) 作为结构起点。
2. 将本 JSON 的 `name`、`shortName`、`tagline`、`quotes`、`contextLines` 合入 `theme.json` 的 `companion`。以实际图片补齐 `artworks`，三个时段各至少有一幅可用图；同一幅可用于多个时段。
3. 按用户图片设定浅深配色、裁切方式、画册标签与署名，确认素材齐全后再将 `sagiri` 加入 `catalog.json`。不修改现有默认主题和用户选择。
4. 验证主题解析、时段换句、提示不重现、应用与小组件显示，再发布新安装包。

后续增删语录仅编辑 JSON 对应数组，保留三个非空池及六个现有情境键，并同步中文阅读版。完整规则见 [主题与角色素材维护](../../主题与角色素材维护.md)。
