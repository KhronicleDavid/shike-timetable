# 每日一言维护

1.12.0新增可选的「每日一言」，默认关闭。在设置中开启后，主页卡片与桌面今日课表展示同一条正文及作品出处；主页保留主题角色立绘，点击角色继续沿用原角色互动与语音规则。下一门课的时间、名称和教室以紧凑一行展示。

主页单击正文或「换句」前进一条；长按正文或「复制」只复制正文，不带作品、作者或破折号。小组件单击短句换下一条，底部「复制一言」复制当前显示条目的完整正文。桌面复制使用显式、非导出的前台透明Activity，不通过后台剪贴板读取或后台启动冒充点击。

每天以手机本地时间08:00为分界，08:00前仍属于前一天的一言周期。手动换句只前进条目，不重置周期，也不把每日定时改成“点击后24小时”。到08:00从当时已选的句子再前进一步；多天未打开时按经过的每日周期补进，相邻页面、重建和普通桌面刷新不会重复前进。关闭开关只隐藏展示，保留选择，不修改课表、角色语录或配音。

Android12及以上若要桌面准点刷新，可在开关下点击「允许08:00准点刷新」，进入系统的“闹钟与提醒”授权。未允许时使用系统允许的非精确刷新，桌面可能延后；应用在前台按分钟时钟跨08:00切换，重新打开时也会按实际时间补换。系统强行停止应用、关机或厂商后台限制仍可能阻止定时投递，恢复运行后不会把手选状态当作定时起点。没有小组件或功能关闭时不保留该每日闹钟；重启、时钟/时区变化、应用升级和精确闹钟授权后重新安排。

## 数据与增量维护

- 数据：`app/src/main/assets/quotes/daily.json`，与主题素材相互独立，当前111条、51个作品名称，19条已玩作品匹配项排在前面。
- 来源：[逐条清单](每日一言来源.md)，含出处页面、上游分类/id和自译说明。设置里的「111条 · 句库与出处」可以浏览正文并点击作品查看源网页。
- 授权说明：同目录`NOTICE.txt`和`AGPL-3.0.txt`。88条来自固定版本的一言开放句库，另23条为核对过来源的短摘；部分据日文翻译，不作为官方汉化文本。
- 生成：`python scripts/build-daily-quotes.py`，仅开发时联网读取固定修订并生成静态数据；手机日常显示、换句和复制均无需联网。开发脚本的缓存位于忽略的`work/`。

手工维护时保留`schemaVersion=1`，增加`version`；每项需有稳定唯一`id`、`text`、`work`、可为空的`speaker`、HTTPS `sourceUrl`。正文含标点不超过50个Unicode字符，不能含换行，不允许正文或id重复。增加/减少条目不需要改Kotlin枚举或固定数组；已经选择的id仍存在时会继续使用，删除该id时回到有效条目。若继续用生成脚本维护，还需同步脚本的筛选或人工短摘列表，避免重建时覆盖手工修改。

请核实作品和摘录位置，未知说话人留空；不要将评论者的感想或临时改写冒充角色原话。对应短句的来源、自译日文或处理说明放在`note`；优先项用`preferred=true`，排在其他条目之前。不要为了凑数量反复收入同一条的不同译法或强行截断长句。

## 测试

JVM用例覆盖111条的长度/去重/出处、07:59:59→08:00、午夜不换、连续手动换句不延后定时、多日补换、循环、时钟回拨、时区及夏令时。

Android用例覆盖默认关闭、开启/关闭/重建、单击、长按和按钮复制正文、角色与一言共存且角色语音不被一言打断、跨实例与并发选择、两个实际AppWidgetHost同步、无点击的后台刷新、复制完整正文、课程列表滚动和大小变化。小组件240dp的最短展示中保留完整一门课程和教室；短句在小尺寸下最多两行，可在较大高度显示三行，复制始终得到完整正文。
