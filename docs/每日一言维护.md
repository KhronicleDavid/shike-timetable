# 每日一言维护

1.12.0新增可选的「每日一言」，默认关闭。在设置中开启后，主页卡片与桌面今日课表展示同一条正文及作品出处；主页保留主题角色立绘与点击互动。1.12.1起，开启每日一言会立即停止正在播放的角色声音，并在应用、设置和桌面入口统一停用语音；关闭每日一言后恢复原本的语音偏好，不更改主题音频文件。下一门课的时间、名称和教室以紧凑一行展示。

主页单击正文或「换句」随机换一条；长按正文或「复制」只复制正文，不带作品、作者或破折号。小组件单击短句随机换一条，底部「复制一言」复制当前显示条目的完整正文。桌面复制使用显式、非导出的前台透明Activity，不通过后台剪贴板读取或后台启动冒充点击。

每天以手机本地时间08:00为分界，08:00前仍属于前一天的一言周期。首次、手动点击和跨周期均随机选句，先等概率选作品，再从该作品选句；多作品时排除当前作品，单作品时排除当前句（仅一条时保留）。普通刷新、页面重建不重抽。手动操作不重置周期、不延后08:00。多天未打开时，恢复后随机换一次并记录当前周期，不为不可见的日期反复抽取；时钟回拨保留选择并重新对齐本地周期。关闭开关隐藏展示并保留选择，不修改课表或原语音偏好。

原始句库也控制平衡：当前211条、83部作品，各作1至5条；CLANNAD原15条、Summer Pockets原9条、AIR原8条均收紧为5条。本次新增117条并移除17条超额条目，净增100条。并非仅靠概率算法掩盖源数据偏重。生成脚本统一别名后按`MAX_PER_WORK=5`检查，超量会直接报错，不能静默丢弃新增条目。JVM验证每作数量和随机分布。

Android12及以上若要桌面准点刷新，可在开关下点击「允许08:00准点刷新」，进入系统的“闹钟与提醒”授权。未允许时使用系统允许的非精确刷新，桌面可能延后；应用在前台按分钟时钟跨08:00切换，重新打开时也会按实际时间补换。系统强行停止应用、关机或厂商后台限制仍可能阻止定时投递，恢复运行后不会把手选状态当作定时起点。没有小组件或功能关闭时不保留该每日闹钟；重启、时钟/时区变化、应用升级和精确闹钟授权后重新安排。

## 数据与增量维护

- 数据：`app/src/main/assets/quotes/daily.json`，与主题素材相互独立，当前211条、83个作品名称，51条已玩作品匹配项排在前面。
- 来源：[逐条清单](每日一言来源.md)，含出处页面、上游分类/id和自译说明。设置里的「211条 · 句库与出处」可以浏览正文并点击作品查看源网页。
- 授权说明：同目录`NOTICE.txt`和`AGPL-3.0.txt`。97条来自固定版本的一言开放句库，另114条为网页短摘；部分据日文/英文翻译，3条纸上的魔法使来自官网角色Q&A（非游戏正文），不作为官方汉化文本。
- 生成：`python scripts/build-daily-quotes.py`，仅开发时联网读取固定修订并生成静态数据；手机日常显示、换句和复制均无需联网。开发脚本的缓存位于忽略的`work/`。

手工维护时保留`schemaVersion=1`，增加`version`；每项需有稳定唯一`id`、`text`、`work`、可为空的`speaker`、HTTPS `sourceUrl`。正文含标点不超过50个Unicode字符，不能含换行，不允许正文或id重复。增加/减少条目不需要改Kotlin枚举或固定数组；已经选择的id仍存在时会继续使用，删除该id时随机选有效条目。若继续用生成脚本维护，还需同步脚本的筛选、原人工短摘列表及`scripts/daily-quote-additions.json`，避免重建时覆盖手工修改。

请核实作品和摘录位置，未知说话人留空；不要将评论者的感想或临时改写冒充角色原话。对应短句的来源、自译日文或处理说明放在`note`；优先项用`preferred=true`，排在其他条目之前。不要为了凑数量反复收入同一条的不同译法或强行截断长句。

## 测试

JVM用例覆盖211条的长度/去重/出处、每作原始数量上限、07:59:59→08:00、午夜不换、手动换句不延后定时、多日恢复、时钟回拨、时区及夏令时；使用固定随机种子验证不同句数作品的等概率机会，以及连续操作不选同作。

Android用例覆盖默认关闭、开关与重建、单击/长按/按钮复制正文、开启一言立即停止现有语音、应用和桌面画像静音换句、设置语音开关不可操作及关闭一言恢复原偏好；跨实例/并发选择、两个实际AppWidgetHost同步、无点击的后台刷新、复制完整正文、课程列表滚动和大小变化。全库211条在200dp和280dp宽、320dp高的真实宿主中逐项测量正文与出处末尾及省略计数，验证完整换行；正常横向铺满、240dp高时保留完整一门示例课程及教室。长课程名和教室同样自然换行，课程区域可上下滚动；字体放大或组件很窄时可向下拉高组件，为课程留出更多空间。
