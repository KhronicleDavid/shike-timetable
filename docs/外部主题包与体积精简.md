# 外部主题包与体积精简

从拾课1.10.0开始，基础安装包只保留简约主题。阳茉莉、纱雾和希尔维娅以独立ZIP提供，导入后可离线使用全部立绘、配色、语录及声音。

## 手机上使用

1. 覆盖安装新版，保留已有课程、学期、作息和交互偏好。
2. 下载所需的主题ZIP，在「设置 → 导入主题包」中选择它。
3. 检查主题名称、版本、素材数量和大小，点击「安装并使用」。同id主题会显示「替换并使用」。
4. 在「整体主题」切换，在「管理主题包」查看占用或移除。移除当前主题会停止播放并回到简约主题，课程保持不变。

1.9.0及之前的内置角色素材不再随APK提供，升级后需要首次导入。原主题选择及首次换句、首次播放提示偏好不重置。已导入主题以后保存在本机，覆盖更新应用无需重新导入；清除应用数据或卸载后需要重新导入。

主题会解包到应用自己的非备份目录，不需要申请存储权限，不执行包内代码，不依赖原ZIP路径。导入后可以删除下载目录的ZIP，避免重复占空间。**外置主要减少基础安装包和后续应用更新下载量，已选用的主题仍占手机存储**。课表JSON备份不包含这些大素材，恢复课表后可独立导入主题。

## 开发与打包

角色源文件在仓库根目录 `theme-packs/<id>/`。每个ZIP对应一个主题，根目录结构：

```text
theme.json
artwork/
  portrait.png
  compact.webp
voice/                 # 可选
  morning_001.ogg
```

也接受上述内容只被一个外层文件夹包裹的ZIP。`theme.json`沿用schemaVersion 1，配色、人物、画册、三时段语录、情境提示与声音映射的格式不变。文件路径使用相对路径，角色插画和配音不必修改Kotlin即可增删。纯配色主题可以省略companion，纯插画主题可以省略quotes。

```powershell
# 生成可直接在手机导入的三个ZIP和校验清单
python .\scripts\package-themes.py
# 默认输出到 dist/themes/

# 调试构建（不带角色大素材）
.\scripts\build.ps1
# 用于分发的精简构建，沿用本机原有签名以覆盖安装
.\scripts\build.ps1 -Tasks @('assembleRelease')
```

新增角色时，在 `theme-packs/` 新建自己的id目录并维护 `theme.json`，打包后导入即可，无需更新应用内注册列表。应用内 `assets/themes/catalog.json` 只注册内置简约主题；仓库 `theme-packs/catalog.json` 仅为完整素材的离线测试索引，新增角色如需参与该组测试再维护此索引。

更新包时保留id，递增 `version`。导入同id会替换旧素材，先完成解包与资源验证，再以原子写入切换注册入口。失败或取消不会覆盖已安装主题。即使同版本重新导入，图片缓存也按独立修订路径区分，不会残留旧图；语音继续按完整中文句子关联。

压缩包最大128MB，解压总量最大256MB，最多1024项，单资源最大24MB、配置最大1MB。检查路径、重复文件、ZIP校验、引用完整性与实际媒体解码。主题名称、描述和语录长度也设有上限，避免异常配置占满界面或内存。图片最多4096×4096且不超过1600万像素，音频不超过2分钟；可使用PNG/WebP/JPEG与OGG/WAV/MP3/M4A。内置简约主题不能被覆盖或移除。

## 实测体积

1.9.0调试安装包为102,054,084字节。1.10.0精简包为1,288,038字节，减少98.7%；拆走角色主题后，未优化的开发包约10MB，再通过R8与资源裁剪降到约1.29MB。两部分优化都已应用。

|文件|大小（十进制MB）|
|---|---:|
|基础APK|1.29|
|阳茉莉主题ZIP|34.55|
|纱雾主题ZIP|21.58|
|希尔维娅主题ZIP|33.37|

ZIP为完整素材，没有降画质。安装包SHA-256为 `78BB6BCE8A4371B91427ADDBCBD1A4BEE51EC8520E92CA73341C36F56BBD3FFC`，各主题包校验值随Release附件提供。

## 已采用的进一步精简

- 分发包启用R8代码优化、混淆与资源裁剪，排除调试界面工具；开发用debug包保留易调试性。
- 保持已有角色素材与声音内容，外置后不降低画质或删减立绘、语录。
- 使用Android自带的图片、音频、ZIP与文件选择器能力，不新增大型主题加载依赖。

R8与资源裁剪的依据见[Android应用优化说明](https://developer.android.com/topic/performance/app-optimization/enable-app-optimization)，文件选择遵循[Android文档访问接口](https://developer.android.com/training/data-storage/shared/documents-files)。

进一步可选方案：使用无损WebP或有损压缩降低主题包下载量，需要另做视觉与透明边缘验证；通过应用商店分发AAB可按设备交付所需资源，但当前直接分发APK仍更方便。按CPU拆包在本项目收益很小：旧包原生库压缩占用仅约37KB。当前最大的收益来自主题外置和代码/资源优化。[Android体积优化建议](https://developer.android.com/topic/performance/reduce-apk-size)

## 验证入口

JVM覆盖ZIP越界、重复路径、缺失素材、配置大小限制和完整引用。Android测试APK才携带角色测试素材，正式APK不携带。系统文件选择结果通过独立测试provider模拟content URI，验证真实读取、预览取消、导入、损坏包拒绝、同版本更新、图片缓存更新、桌面展示、语音和移除流程。

```powershell
.\scripts\build.ps1 -Tasks @('testDebugUnitTest','lintDebug','lintRelease')
.\scripts\build.ps1 -Tasks @('assembleDebug','assembleDebugAndroidTest','assembleRelease')
# 安装对应APK和测试APK，使用 com.shike.timetable.ThemeTestRunner 运行。
# -e themeFixtures false 用于仅简约初始状态的 ExternalThemeImportTest。
# 精简包另通过系统文件选择器和实际界面做黑盒验证，不添加仅供测试的保留规则。
```

签名私钥不纳入仓库。迁移构建电脑时需自行备份并沿用原签名，才能继续覆盖用户设备上的既有安装。

精简构建的R8映射文件在 `app/build/outputs/mapping/release/mapping.txt`，本机另备份到 `dist/拾课-1.10.0-R8-mapping.txt`，供后续排查混淆后的错误。
